# Автотест «Работа с заявками клиентов» (Vanessa Automation)

Сценарий: `ВКМ_РаботаСЗаявками.feature` (в этом каталоге).

## Что проверяет сценарий

| № | Пользователь | Действия |
|---|---|---|
| 01 | Менеджер | Создаёт два документа «Обслуживание клиента» на ноябрь 2026 г. для клиента «ООО Тест ВКМ» по договору «Тестовый договор» и специалиста Иванова |
| 02 | Специалист | Открывает созданные обслуживания, заполняет выполненные работы (3 строки в каждом документе, 4 и 5 часов к оплате) и проводит документы |
| 03 | Бухгалтер | Обработкой «Массовое создание актов» создаёт акты (реализации) за ноябрь 2026 г. |
| 04 | Бухгалтер | Формирует отчёт «Анализ выставленных актов» за ноябрь 2026 г. по клиенту «ООО Тест ВКМ» и сравнивает результат с эталоном |

Эталон отчёта: к выставлению **9 часов / 18 000 ₽**, выставлено по номенклатуре «Работы специалиста» **9 часов / 18 000 ₽**, не выставлено — **0**.
(Абонентская плата договора — 10 000 ₽, стоимость часа — 2 000 ₽; 9 ч × 2 000 ₽ = 18 000 ₽.)

## Требования к окружению

- Платформа 1С:Предприятие 8.3.27 или новее (тонкий клиент).
- Vanessa Automation **single** версии 1.2.042 или новее: https://github.com/Pr-Mex/vanessa-automation/releases (архив `vanessa-automation-single.<версия>.zip`, внутри файл `vanessa-automation-single.epf`).

### Отключение защиты от опасных действий

Иначе при открытии Vanessa Automation платформа будет бесконечно запрашивать подтверждение.

1. Откройте Блокнот **от имени администратора**.
2. Откройте файл `conf.cfg` платформы: `C:\Program Files\1cv8\conf\conf.cfg` (для 32-битной платформы — `C:\Program Files (x86)\1cv8\conf\conf.cfg`). Если в нём есть строка `ConfLocation=...`, откройте также файл `conf.cfg` в указанной там папке.
3. Добавьте отдельной строкой:
   ```
   DisableUnsafeActionProtection=.*
   ```
4. Сохраните файл и перезапустите 1С.

## Подготовка базы

1. Скачайте демонстрационную базу (`*.dt`) из раздела **Releases** репозитория.
2. Создайте **новую пустую** информационную базу и загрузите в неё dt-файл (Конфигуратор → *Администрирование* → *Загрузить информационную базу*).
3. В базе уже есть всё необходимое для теста:
   - пользователи с пустыми паролями и аутентификацией 1С:Предприятия:

     | Пользователь | Имя для входа | Профиль |
     |---|---|---|
     | Администратор | `Администратор` | Администратор |
     | Смирнова Ольга | `Менеджер` | ВКМ Менеджер |
     | Иванов Сергей | `ИвановС` | ВКМ Специалист |
     | Кузнецова Мария | `Бухгалтер` | ВКМ Бухгалтер |

   - клиент «ООО Тест ВКМ» и абонентский «Тестовый договор» (01.01.2026 – 31.12.2027, абонентская плата 10 000 ₽, стоимость часа 2 000 ₽);
   - заполненные константы «Номенклатура абонентская плата» и «Номенклатура работы специалиста»;
   - условия оплаты сотрудников (процент от работ для специалиста Иванова).
4. В базе **не должно быть** документов «Обслуживание клиента» и «Реализация товаров и услуг» за ноябрь 2026 г. по клиенту «ООО Тест ВКМ» (в демонстрационной базе их нет).

> Сценарий создаёт документы, поэтому эталон совпадает только при **первом** запуске на чистой базе. Для повторного запуска заново загрузите dt-файл (или пометьте на удаление и удалите документы теста за ноябрь 2026 г.).

## Запуск

1. В стартере 1С выберите базу → **Изменить** → на последней странице в поле **Дополнительные параметры запуска** укажите `/TESTMANAGER` → **Готово**.
2. Запустите базу в режиме 1С:Предприятие под пользователем **Администратор**.
3. Меню **Файл** → **Открыть** → `vanessa-automation-single.epf`.
4. В Vanessa Automation: **Открыть feature файл…** → `tests\ВКМ_РаботаСЗаявками.feature`.
5. Нажмите **Выполнить сценарии** (зелёная стрелка).

Vanessa Automation сама запускает отдельные сеансы (TestClient) под пользователями Менеджер, ИвановС и Бухгалтер. Время выполнения — около 2–3 минут.

**Ожидаемый результат:** все 4 сценария выполнены, в журнале Vanessa — «Выполнение сценариев закончено. Ошибок не было.»

## Возможные проблемы

| Симптом | Решение |
|---|---|
| Бесконечные окна «Текущее выполнение действия было прервано для выдачи предупреждения» | Не отключена защита от опасных действий — см. раздел «Требования к окружению» |
| «Не получилось подключить профиль TestClient» | Закройте все сеансы 1С (в т.ч. процессы `1cv8c.exe` в Диспетчере задач) и запустите тест заново; проверьте, что у пользователя пустой пароль и включена аутентификация 1С:Предприятия |
| Не совпадает эталон отчёта | Тест запускался повторно — загрузите dt-файл заново |
| Окно о лицензии для разработчиков при запуске клиента | Нажмите «ОК», на выполнение теста не влияет |
